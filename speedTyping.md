# Create a speed typing game
- Player types as fast as they can within the given time frame

**Levels**
- Each level is the same sentence/word but shorter time.
    - Level 1: 30s
    - Level 2: 20s
    - Level 3: 10s
    - Level 4: 5s
    - Level 5: 3s

**Game Example**
- type [hello] within 10s
    - press enter when done
    - display time
    - next [enter]
- You win

- type [hello world] with in 10s
    - press enter when done
    - display time
    - next [enter]
- you win

- type [hello world! I am ] with in 10s
    - press enter when done
    - display time
    - next [enter]
- you win 

**Game Function**
- Have screen with white background
- display text that needs to be typed
- show text "green" when key is correct
- show text "red" when key is wrong
    - can't move forward until corrected
    - need to delete keys to fic mistake

- when completed press enter
- show elapsed time
- press enter to go to next lvl

- When time runs out game is over
